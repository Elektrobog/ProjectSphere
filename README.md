# ProjectSphere

3D-платформер: шар проходит препятствия на вращающихся платформах вокруг колонны.
Физическое управление (Rigidbody), реалистичное сцепление с движущимися объектами.

## Ветки

- **main** — стабильная версия
- **test-speed** — тест механики центробежного сноса шара с быстрых платформ

## Структура проекта

| Путь | Назначение |
| --- | --- |
| Assets/Code Column | Скрипты колонн и генератор спиральных платформ |
| Assets/PlatformCode | Движущиеся/вращающиеся платформы, интерфейс скорости |
| Assets/Level 1 Code | Механики первого уровня (лифты, кнопки, зоны падения) |
| Assets/Шар | Шар игрока: контроллер, прыжок, склоны, проверка земли |
| Assets/Menu Code | Главное меню, пауза, загрузчик |
| Assets/Over Code | Таймер уровня, триггеры |
| Assets/Scenes | Сцены: Level 1, MainMenu |
| Assets/PreFab | Префабы игрока, кнопок, колонн |

## Ключевые скрипты

- **BallController** — контроллер шара: крутящий момент, сцепление с платформой (grip),
  позиционный якорь, центробежный снос (Centrifugal Drift), торможение, воздух.
- **RotatingPlatform** — кинематическое вращение платформы вокруг колонны;
  отдаёт свою скорость через IPlatformVelocityProvider (физика игрока её наследует).
- **SpiralStepSpawner** — генерирует платформы по спирали вокруг колонны из списка настроек;
  сам добавляет RotatingPlatform к созданным платформам.
- **GroundCheck** — проверка земли рейкастами (угол, нормаль, тайминг).
- **BallSlopeSlide** — скатывание с крутых склонов (порог 40°).

## Правила работы с ассетами

- Переименовывать/перемещать ассеты **только внутри Unity** (окно Project), иначе сломаются GUID-ссылки.
- Служебные папки редактора (UserSettings, Library, Temp) в git не попадают.
